Built for the tiny moments that interrupt deep work.

Clippa is not a heavy productivity suite. It is a small, native Mac utility that saves you from copying the same thing twice.

⌘

Fast popup

Summon your history with Cmd+Shift+V. Use arrow keys, number keys, Return, and Space without reaching for the mouse.

⌕

Search everything

Find old copies by typing a few letters. Text, links, source app names, and timestamps stay easy to scan.

▣

Image history

Images and screenshots are stored with thumbnails, so the thing you captured does not disappear after the next copy.

↑

Pinned items

Keep frequently used clips close. Pin important items and remove noise when the history gets crowded.

Q

Paste queue

Queue several saved items and paste them one after another. Handy for forms, reports, support replies, and repeated work.

T

Saved text

Store short reusable text and templates with date, time, clipboard, and cursor placeholders.

Small window. Big relief.

The interface stays compact, readable, and close to macOS. It is meant to be opened for a second, then disappear.

Install Clippa from GitHub Releases.

Download the latest release, move Clippa to Applications, grant Accessibility permission when prompted, and your Mac gets clipboard history.

macOS 12 or later recommended. Apple Silicon and Intel builds are packaged as a native Mac app.
